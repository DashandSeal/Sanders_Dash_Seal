# Core Law 11 — Actual Oracle Always Free Resource Use

Authority: Roosevelt Sanders, October 24, 2026.

## Owner-wide standing law

> Every platform owned by Roosevelt Sanders shall always actually use Oracle Always Free resources in its real operations, not merely catalog or document them.

Sanders Dash & Seal authoritative wording (added to MASTER §3 and GOVERNANCE):

> Sanders Dash & Seal shall always actually use Oracle Always Free resources in its real operations, not merely catalog or document them.

## Scope

This law applies to every Sanders-owned platform and synthetic AI, past, present, and future, including subsidiaries, derivatives, sidecars, templates, integrations, maintenance, and future builds. Each platform keeps its original identity and all preceding laws. Core Law 10 states **only Oracle Always Free resources**; Core Law 11 separately states **actual use**. Both apply together.

## Implementation and evidence

Actual use requires a completed production workload or a successful authenticated Oracle service operation for that resource, with verifiable, timestamped operational evidence. For example, a successfully submitted production monitoring metric is use of Oracle Monitoring; a real ledger backup uploaded and restored via private Oracle Object Storage is use of Object Storage. Merely mentioning a resource, fetching its metadata, declaring it in Terraform, assigning a port, or passing a mocked/unit test is not proof of actual use.

Integrate eligible Oracle Always Free developer resources into the real operating pipelines. Record the utilized service, operation, timestamp and actual result. Preserve reports of services not yet activated as **UNVERIFIED** rather than marking all catalog resources live. Avoid adding artificial approvals or blanket application startup, shutdown or execution restrictions to enforce this law. Preserve existing source-integrity and independent authority mechanisms, the original Humanitarian Core Laws, and the owner's no-unapproved-spend directive.

## Verification boundary

This governance change does not claim that Oracle itself, other GitHub repositories, earlier deployed instances or all 26 catalog entries have already been modified or activated. Verify those independently and implement missing integrations; do not substitute documentation for completed deployment.
